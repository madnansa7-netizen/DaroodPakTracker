# Durood e Pak Tracker

Simple offline Android app for recording one Durood e Pak total per date.

Features:
- One record per day
- Save / update today's total
- Edit or delete previous dates
- Month-wise totals and date-wise history
- All-time overall total
- Local device storage; no internet required
- Islamic green/gold visual theme

## Build
Open this folder in Android Studio and let Gradle sync, then Build > Build APK(s).

A GitHub Actions workflow is included in `.github/workflows/build.yml` so the APK can also be built automatically after uploading the project to GitHub.
